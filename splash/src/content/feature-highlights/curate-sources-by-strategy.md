Start from how you actually think about the work. Spin up a strategy — or a
topic, a thesis, a market segment, whatever lens fits — and start gathering the
sources that support it. Each source begins as a simple link; when you're ready,
pull in the full text with one click.

Real reports are messier than a tidy link, and Augment It handles that. When the
link is a summary page but the actual report is a separate PDF — often locked
behind a "verify you're human" wall — just drop in the file you downloaded
yourself. It files itself under the right source, keeps the page you'd cite, and
even shrinks a bloated 30MB report down to something sensible. Fix a title,
rename a file, add a tag like `Impact-of-AI` exactly the way you typed it — every
change lands in your library and in the file on disk at the same time, so what
you see is always what's saved.
